The base measurement panel allows you to set the primary bounds for your instrument, as well as providing fields for basic file properties. The panel renders two rectangles to represent the bounding areas.

## Inner Versus Outer
It is important to understand the violin making process for real instruments, as this is what guides CremonaCad. A maker always starts with a mould, which the ribs are bent around. Traditionally, the maker will trace the outline of the ribs onto the top and back, with a small offset which will become the overhang. The overhang and rib width are defined on this panel, creating and inner and outer bounding box. The first few panels will draw arcs within the inner bounding box, so as to form the boundries of the mould.

## Reference Images
It is likely that you will want to use an existing image as a reference, this panel is a sensible plac to upload and scale images. It is recommended that you find not only images, but also measurements for your reference instrument. Many online sources, such as Tarisio, will often publish measurements of the body along with their images. 

### Adding the image
Once you have your reference image, you can paste it onto the canvas, or upload it from your machine. To do this, select the reference image tool on the bottom bar, and then click upload. 

### Scaling the image
Use  bounding box to scale your reference image. Select the image and use the handles on the corners and sides to scale it. 

You may also scale a reference image by drawing measurement lines over known distances, which may help with some images. To do this, go into the toolbox and select the distance tool. Then draw a line across a known distance, which will be reported above the line. You may also edit the distance manually, select the line and edit the distance text box on the bottom bar. Once you have the known length, the reference image can be scaled using its handles.

Do keep in mind [[perspective]] when scaling images.

## Fields

| Field | Description |
|---|---|
| Height | The outer height of the instrument. |
| Width | The total width of the instrument, almost always the width of the lower bout. |
| Overhang | The amount the top and back plate project over the ribs. |
| Ribs | The thickness of the ribs. |
