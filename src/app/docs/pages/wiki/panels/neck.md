This panel allows you to define the shape of the neck. Unlike some of the other panels, the neck system for violin based instruments is fairly a straightfoward system mostly composed of straight edges. 

This panel allows you to define the neck in three dimensions. Here, width refers to the width of the neck accross the body or X-axis. Thickness refers to the depth of the neck system into the Z-axis. 

## Reference Image Notes
It can be difficult to find side profile images of a historical violin where the whole length of the neck is shown, along with the body, such that you may accurately scale the neck and scroll against the body. The largest concern here is usually getting the correct string length, but don't worry, there is a [[string-setup]] panel where you can tune that later.
