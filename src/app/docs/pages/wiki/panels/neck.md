This panel allows you to define the shape of the neck. Unlike some of the other panels, the neck for violin-based instruments is a fairly straightforward system mostly composed of straight edges. 

This panel allows you to define the neck in three dimensions. Here, width refers to the width of the neck across the body, the X-axis. Thickness refers to the depth of the neck into the instrument, the Z-axis. 

## Reference Image Notes
It can be difficult to find side profile images of a historical violin where the whole length of the neck is shown, along with the body, such that you may accurately scale the neck and scroll against the body. The largest concern here is usually getting the correct string length, but don't worry, there is a [[string-setup]] panel where you can tune that later. 

## Fields
**Neck**

| Field | Description |
|---|---|
| Length | From the floor of the mortise to the foot of the nut, along the fingerboard plane. This is what places the nut. |
| Thickness Upper - Lower | The depth of the neck wood alone, without the fingerboard. Upper is taken square to the fingerboard at the nut, lower through the button tip. |
| Width Upper - Lower | The width of the neck at the nut and at the root. |

**Heel**

| Field | Description |
|---|---|
| Heel Radius | The cove that sweeps from the neck's back down to the button, drawn as one arc tangent to the back. |
| Heel Angle | The heading of the foot as it leaves the button tip, in degrees off level. |
| Button Height | How far the button's tip stands beyond the end of the plate. The same value as on the plate contour panel. |

**Mortise**

| Field | Description |
|---|---|
| Mortise Depth | How deep the neck's foot sits into the upper block, measured from the outer face of the ribs. |
| Overstand | How far the underside of the fingerboard stands above the edge of the top plate at the neck root. |
| Neck Angle | The tilt of the fingerboard plane off square to the top plate, in degrees. |
