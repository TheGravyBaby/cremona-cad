A smaller update geared towards improving the PDF exports and panel flow. 

- **Schematic PDF** — Previous patches only exported large path traces drawn to scale. This version introduces a compact schematic document that can be printed on standard paper. 

- **Corner and Bout panel refactor** — There have been a few arcs moved in the early panels to allow for more coherent bout design. 

- **Mould Clamp Patterns** — The mould panel now provides multiple options for final export. "Window" renders a frame like structure, while "holes" produces a more classical tempate with simple clamping holes. You can also choose "none" and customize your mould yourself. Alignment holes for the ribline contour have also been added.
