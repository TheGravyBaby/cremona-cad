Drawing Tools

The toolbar on the left side is a drafting set, allowing you to mark up the canvas. Drawings you make save save to your recipe file, but do not interact with the instrument render.

Drawing a shape

Drag or click
Most tools can be used by selecting the tool and then clicking on the canvas.
Letter key
Line, Arc, Circle, Rectangle, Section, Text, Point, Offset, Image. Press again to step through a button's variants.
Shift
Lock a line to 30/45/90°, force a square, or ask an arc for its other solution.
Ctrl / ⌘
Lock a line to the tangent of whatever curve you started on. Add Shift to run square to it instead. Dragging a placed line's end, it keeps the line's angle.
Type a number
After the first click, sets the size instead of the pointer: a length (length,angle to set the direction too), a radius, or a box's width,height. Enter places it.
Escape / right-click
Abandon the shape, then back to Select or clear a selection.

The Color swatch in the bottom settings bar sets the selected shape's color.

Snapping

Points pull onto existing geometry. A path snap also captures the path's direction, which is used for making tangent arcs and lines.

Arcs

  • Center First — click the center, then the arc's start, then its end.
  • Center Second — the same three points, with the arc's start clicked before the center.
  • Center Last — click both ends of the arc, then its center. The center is pulled onto the line halfway between the ends, so it only needs clicking by eye.
  • Three Point — click both ends, then a point the curve passes through. No center anywhere in it, which is what makes it the one to trace a shape you can see. Shift takes the rest of the circle instead.
  • Tangent Arc — click on an existing curve, then an end point; the radius is solved for a smooth join.
  • Chained Arc — each click adds another tangent arc; Escape ends the chain. Each arc stays its own shape.
  • Join Arc — click an endpoint on two curves to bridge them. Shift cycles the join options.

Offset, dimensions, sections

  • Offset — select a shape or a group first, then click the offset tool. Move your mouse to select the amount of offset or type a number and press Enter for an exact distance. Shapes meeting end to end offset as one path.
  • Dimension — a measured, labelled line between two points.
  • Section — divides a line into weighted parts in alternating colours; set them in the settings bar as fraction or a comma seperated list eg [3,4,3].

Text

Click to place a label and type straight into it. Double-click an existing one to edit it again, or press Enter with it selected. Enter finishes, Shift+Enter adds a line, Escape discards what you typed.

  • Size — in millimetres, measured on the drawing rather than the screen, so a label keeps its proportion as you zoom. The size you set becomes the size for new labels.
  • Angle — degrees counterclockwise, for reading along a rib or a centreline. A selected label also carries a round handle above it to turn by hand.

Images

You can upload and scale images using the Image tool - located on the left toolbar.

  • A new image is unlocked by default: click and drag to do operations on it, or use the settings bar.
  • Mirror flips the picture left–right.
  • Drop White will make the white background of images translucent.
  • Lock will disable canvas interactions with the image. Images from templates and saved files start locked; click the name in the panel to unlock.
  • The eye on the Image button toggles the view on all images.
} @if (tutorialTopic === 'base') {

Base Measurements

The instrument's primary dimensions, and basic file properties.

  • Set height and width here first. If you are tracing a historical instrument, these measurements can usually be found online. It is recommended to upload a reference image and then scale it to the bounding box rendered on this panel.
  • Ratios appear beside many metric values — Cremonese instruments often use simple integer ratios to define their arc segments.
  • The arcs you will draw will be inset from the outer edge a distance equal to the rib thickness + the overhang. We have to draw the instrument starting from this inset to connect our corners and form a mould.
} @if (tutorialTopic === 'bouts') {

Main Bouts

The upper and lower sections of the body — the first arcs you create.

  • The upper and lower bouts are primarily defined by two outer arcs with a central join arc.
  • Each bout's width corresponds to the outer width of the instrument. For historical instruments, these measurements can be found online.
  • Viol Neck adds a viola da gamba-style upper extension, common on double bass.
} @if (tutorialTopic === 'corners') {

Corners

Corner positions, and the arcs connecting them to the main bouts.

  • Each corner has XY controls for precise placement.
  • Use Viol Corner gives viol-style corners, with a single connecting arc.
  • You can use the Compound button to allow more complex corner shapes.
} @if (tutorialTopic === 'center') {

Center Bout

The narrowest section, connecting the upper and lower bouts.

  • Center Bout Width is the total outer width at the waist, and holds constant as you adjust the C0 circle.
  • Fit C0 to Bouts solves C0 to intersect U2 and L2 cleanly — Kevin Kelly's four-circle method, still open to manual adjustment.
  • Like the previous panel, you can adjust the corner position. The Compound button to allow more complex corner shapes.
} @if (tutorialTopic === 'outer') {

Outer Path

The corner arcs and button that complete the outline.

  • The shape of the outer corners are defined by cutting a line between the two corner circles.
  • The button is the semicircular tab at the neck joint of the back plate.
} @if (tutorialTopic === 'purfling') {

Purfling

The narrow inlaid strip set just inside the plate edge.

  • Offset — how far in from the edge the channel begins.
  • Width — the channel's span.
} @if (tutorialTopic === 'fluting') {

Fluting Channel

The small "moat" around the edge of the plate. It is gouged before the arch is carved.

  • IRL the fluting channel is carved with a gouge. Sweep defines the radius of the gounge you would use for this step. Depth defines the depth of the channel.
  • Land Edge — where the channel starts, measured from the plate edge.
  • The channel runs past the corners. Gouge Corners smooths the area between the fluting channel and the corners. This is useful for STL exports but is left optional.
  • The C Bout button allows for a narrower fluting channel through the Center Bout.
} @if (tutorialTopic === 'long') {

Long Arching

The lengthwise profile of the plate.

  • A Catenary is obtained by dangling a string between two points. Spline allows you to place control points, including asymmetric points.
  • Arch Height — peak height above the plate edge.
  • Thickness — plate thickness at that edge.
  • A spline point's Mirror toggle repeats it at the opposite end. Turn it off and the two sides can be shaped independently.
} @if (tutorialTopic === 'cross') {

Cross Arching

The cross-section across the width of the plate.

  • The Station slider previews the profile along the body. Its ticks are the five usual sighting positions — the two widest points, two corners, waist.
  • Cross arching can be defined using cycloid curves or splines.
  • + Set Station pins the current cross-section at the height you are previewing. Each station holds its own shape and the surface flows between them — a rounder centre bout and flatter ends, for example.
  • Wireframe and Contour Map show the interpolated surface in 3D.
} @if (tutorialTopic === 'fHolePlacement') {

F-Hole Placement

This panel places the eyes and the central stem of he f-holes.

  • Upper Eye / Lower Eye — radius and center (X/Y) of each eye circle. Eye Distance and Ur to Lr ratio are calculated display values.
  • Rise — how far the f-hole's bounding box extends past each eye, top and bottom. H to W is that box's height-to-width ratio.
  • Stem — width, center, and lean Angle of the straight section joining the eyes.
} @if (tutorialTopic === 'fHoleContours') {

F-Hole Contours

This panel defines the arcs that join the eyes and give the f-hole its characteristic shape.

  • Each side runs two arc chains that reach from the eye to the stem. The arc groups are split into uper, lower and stem sections. A compound arc can be added to the system if a more complex shape is required.
  • The Wing is defined by a straight cut to the eye which leaves a small flap. You can set the wings length, the position along the eye which it intersects, as well as its slope.
} @if (tutorialTopic === 'mould') {

Mould

The strucure which the ribs are bent around.

  • Four blocks — Upper, Upper Corner, Lower Corner, Lower — each with height and width.
  • Corner Pad adds material at the corner point, which helps in placing the block against the mould.
  • Bit Diameter if cutting on a CNC internal right angles are not possible, this adds a small radial cutout at these points.
  • Clamping channels run parallel to the edges by default. A simpler mould pattern can be defined with a box cutout instead.
  • The bar at the foot of the panel draws the blocks and inner path over the mould.
