This panel allows you to define the width of the scroll and pegbox system. The widths are divided into sections for the front and back of the pegbox, and a section for the volute turns. Due to the large number of parameters, I have elected to use names for various sections correlating to body parts. The "foot" sits low on the pegbox, while the "hips" and "poll" sit higher. 

Note that for most violins, the duck tail smoothly joins the width of the back, whereas for some violas and for most cellos, the duck tail is notably smaller than the width of the pegbox system. 



## Fields
All widths are full widths, cheek to cheek. The front is sawn straight, so its widths are placed by height. The back is carved off the volute, so its widths are placed by distance along the path.

**Front**

| Field | Description |
|---|---|
| Throat | The front's width at the foot of its straight. |
| Hip | The pegbox's widest point beside the nut. |
| Hip Y | How far above the nut's top the hips sit. 0 for no hips. |

**Back**

| Field | Description |
|---|---|
| Crown | The back's width at the crown, the top of the head. |
| Poll | The back's width at the poll, its furthest reach. |
| Foot | The back's width at the top of the duck tail's round. |
| Duck Tail | The diameter of the round where the pegbox's back dives into the neck. |
| Straight | How far the duck tail's sides run straight up to the foot, by height. 0 for none. |

**Volute Turns**

| Field | Description |
|---|---|
| Turn 1 Bottom | The width at the bottom of the first turn. |
| Turn 2 Top | The width at the top of the second turn. |
| Turn 2 Bottom | The width at the bottom of the second turn. |
| Eye | The width at the eye. The last turn is this wide from its top on in. |

**Neck**

| Field | Description |
|---|---|
| Width | The width of the neck at the nut, the same value as on the neck panel. |
| Nut | The width of the nut. |
