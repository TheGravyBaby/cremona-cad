There are numerous keyboard controls and hotkeys that make using CremonaCad significantly easier. 

On a Mac, *Cmd* works wherever *Ctrl* is listed. 

## Moving around the canvas

|---|---|
| *F* | Fit everything in view |
| *Scroll wheel* | Zoom |
| *Touchpad Pinch* | Zoom |
| *Double-click* | Zoom in at the pointer |
| *Shift + double-click* | Zoom out at the pointer |
| *+ / −* | Zoom in / out |
| *Two-finger scroll* | Pan |
| *Middle mouse button* | Pan |
| *Space + drag* | Pan |
| *Arrow keys* | Pan, when nothing is selected |
| *Shift + arrow keys* | Pan further |

## Fields in a panel

| Control | Does |
|---|---|
| *↑ / ↓* | Step by the field's step |
| *Shift + ↑ / ↓* | Step by 10 |
| *Ctrl + ↑ / ↓* | Step by 0.1 |
| XY point field: *arrow keys* | Move the point; ← → change x, ↑ ↓ change y |
| XY point field: *Escape* | Restore the point as it was when you entered it |

## Selecting objects

|---|---|
| *Click* | Select an object |
| *Shift + click* | Add to or remove from the selection |
| *Click + Drag* on empty canvas | Select by area |
| *Shift + drag* on empty canvas | Add to the selection by area |
| *Drag* a selected shape | Move it |
| *Drag* an endpoint handle | Reshape it. Endpoint handles are indicated by small triangles on the shape when selected. |
| *Double-click* a group | Open the group to edit one member |
| *Double-click* a batten | Edit its pins |
| *Double-click* a label, or *Enter* | Edit the text |
| *Right-click* | Edit menu |
| *Escape* | Clear the selection |

## Editing a selection

|---|---|
| *Arrow keys* | Nudge 1 mm |
| *Shift + arrow keys* | Nudge 10 mm |
| *Ctrl + arrow keys* | Nudge 0.1 mm |
| *Delete / Backspace* | Delete |
| *Ctrl + C / X / V* | Copy / cut / paste |
| *Ctrl + D* | Duplicate onto the active layer |
| *Ctrl + G* | Group |
| *Ctrl + Shift + G* | Ungroup |
| *Ctrl + Z* | Undo |
| *Ctrl + Shift + Z*, *Ctrl + Y* | Redo |

## While drawing

|---|---|
| Line: *Shift* (held) | Lock to common angles: multiples of 30° and 45° |
| Line: Type a number, then *Enter* | Set the length exactly. Angle and starting point are preserved.|
| Line: *Ctrl* (held, while dragging) | If the line was started on an edge, holding *Ctrl* locks the line angle to the tangent of that edge.  |

| Arc: *Shift* | Use the longer arc length between the two points |
| Join Arc: *Shift* | Cycle through the possible joins |

| Polyline: *Enter* or *double-click* | Finish |
| Polyline: *Backspace* | Remove the last point |

| Text: *Shift + Enter* | New line |
| Text: *Enter* | Finish the label |
| Text: *Escape* | Abandon the edit |

| *Escape* | Clear, deselect tool |
| *Right-click* | Same as *Escape* |

| Move, Rotate, Scale, Offset: type a number, then *Enter* | Apply that amount |

## File

| Control | Does |
|---|---|
| *Ctrl + S* | Save |
| *Ctrl + O* | Open |
